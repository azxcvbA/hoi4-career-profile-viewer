# HoI4 キャリアプロフィール 一括ビューア

Hearts of Iron IV のキャリアプロフィール（`.pr`）に含まれる国家タグ付き統計レコードを、一画面で表示する非公式ビューアです。

## 使い方
1. GitHub Pagesで公開したサイトを開く。
2. `career_profile_..._v3.pr` をドロップするか、ファイル選択ボタンで選ぶ。
3. 国家名・国家タグで検索したり、記録グループを切り替える。
4. 統計の内部IDを選び、ブロック A / B の数値で並べ替える。
5. 詳細から各国家の全数値を表示し、CSVで保存する。

## 動作確認に使用したファイル
- `career_profile_EBA6043001001001_v3.pr` と同じ構造のファイル
- 4グループ、国家タグ付きレコード 221 件、異なる国家タグ 198 種
- 各レコードには 2 つの数値ブロック（内部ID `0x28DE` / `0x28DF`）があり、それぞれ 167 項目を含む
- MOD名 `Millennium Dawn` と `tgwr_career_profile` が識別できる

## 重要な制限
**統計の内部IDとゲーム内表示名の対応関係は、まだ検証されていません。**

そのため、`0x3E2B` などのコードを項目名として表示し、値を「プレイ回数」「勝利数」などと断定していません。64ビット型についても生の符号なし整数で表示しており、単位・意味の解明は今後の課題です。

最初の実装は、特定バージョンの `.pr` を解析するものです。別のバージョンでは読み込みに失敗する可能性があります。

## プライバシー
- ファイルはブラウザ内の JavaScript だけで読み込みます。
- `.pr` ファイルの内容をGitHubなどのサーバーへ送信しません。
- このリポジトリには個人のキャリアプロフィール実データを含めていません。
- GitHub Pagesは公開ホスティングです。閲覧サイトそのものには誰でもアクセスできます。

## GitHub Pages の公開設定
GitHub の **Settings → Pages → Build and deployment → Deploy from a branch** で、ブランチを **main**、フォルダを **/(root)** に指定し、**Save** を押してください。

サイトURL（公開設定完了後）:
https://azxcvba.github.io/hoi4-career-profile-viewer/

## 開発方針
ゲーム内の統計との照合が取れた項目から、コードを正式な項目名に置き換えていきます。検証されていない推測は仕様として組み込みません。
